Animal Shelter Manager (ASM3) manages animals, adoptions, foster homes, veterinary
care, people, volunteers, donations, documents, reports and online forms.

This YunoHost package runs the official Python application behind YunoHost's Nginx,
with a private local WSGI service and MariaDB. It initializes the administrator,
installs bundled templates and reports, schedules daily work, and supports upgrades,
backups, restoration, URL changes and multiple instances.
