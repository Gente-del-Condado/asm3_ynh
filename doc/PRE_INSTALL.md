Requires YunoHost 12.1.17 or newer. Supports domain roots and subpaths.
Reserve 512 MiB available RAM, 2 GiB for code/dependencies and space for documents.

The selected YunoHost user becomes ASM3 administrator through native portal SSO.
Other authorized staff receive automatic read-only profiles. Application roles
remain managed in ASM3. No separate initial password is requested.

The package follows stable upstream releases. Apply upgrades through YunoHost.
